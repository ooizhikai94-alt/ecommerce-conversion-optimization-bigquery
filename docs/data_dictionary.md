## Dataset # This is the Dataset that i used

**BigQuery Public Dataset**

`bigquery-public-data.google_analytics_sample`

The dataset contains Google Analytics session-level data with nested hit-level interaction data.


## Session Identification Fields

| Field | Description | Used For |

| `fullVisitorId` | Identifier associated with a visitor | Identifying sessions |
| `visitId` | Identifier for a visit/session | Identifying sessions |
| `date` | Date associated with the session | Temporal analysis when required |
